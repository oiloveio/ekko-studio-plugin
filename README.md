# Ekko Studio 飞书 CLI 插件

将官方 `lark-cli` 暴露为 Studio Agent 工具 `lark-cli__run`。插件随附 [官方 v1.0.100 发行包](https://github.com/larksuite/cli/releases/tag/v1.0.100)，首次调用时校验 SHA-256 并解包到插件数据目录，不调用系统 PATH 中的 CLI。该版本是 2026-11-23 核查时的最新正式版，不会自动更新。支持 Linux x86_64、Linux ARM64 和 macOS ARM64；需要系统 `tar`。安装后仍需在 Studio 服务器对应操作系统账号下单独完成飞书授权。登录态不与 Studio 用户或 Profile 自动绑定；所有能够调用该工具的 Studio 用户可能使用同一飞书身份。仅在信任所有调用者的环境启用。

## 安装

需要支持插件 SDK v1 的 Ekko Studio、Node.js 和服务器端 `tar`。在插件中心填写本插件目录的服务器绝对路径，确认信任后启用。安装到远程 Studio 时路径必须位于远程服务器或容器内。无需 npm install 或构建；服务器无需另装 lark-cli。插件数据目录必须允许执行文件。

安装后刷新 Agent 的 MCP 工具列表或开始新会话。工具使用示例：`{"args":["docs","--help"]}`、`{"args":["schema","drive.file.list"]}`。首次调用后，官方 CLI 位于 Studio 为本插件提供的数据目录下，文件名为 `lark-cli-1.0.100`；登录和配置需以 Studio 进程的系统用户身份在服务器终端执行该文件。请求失败应检查退出信息、飞书应用权限和登录态。插件数据目录的实际路径请以服务器部署配置为准。

工具可能执行飞书写操作，应仅按用户授权执行；它不代替 Studio 的访问控制。插件拒绝显式的 `--yes` / `-y`，但原生 API 等入口仍可能执行写操作，这项检查不是审批或安全边界。CLI 可能读取或写入服务器文件；不要把工具开放给不可信用户。子进程不经过 shell，最多运行 110 秒，输出上限 1 MiB，超出需缩小范围或分页。处理带有敏感信息的查询时，注意工具输出可能进入会话记录。

## 测试

运行 `npm test`。本地单元测试不代表宿主已成功安装或远程飞书权限已经验证。
